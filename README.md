> **No longer operating.** This company or product has shut down, been discontinued, or been deprecated. This profile is kept as a historical record and is not maintained or rated.

Orbit is a developer relations and community intelligence platform offering a comprehensive RESTful API that enables tracking of member activities, measuring community growth, and managing developer advocates and contributors. The service provides endpoints for activities, members, organizations, notes, reports, and webhooks, allowing seamless integration of community data into internal tools and analytics pipelines. Although Orbit was acquired by Postman in April 2024 and the original platform was discontinued, the API specifications continue to be maintained for legacy integrations, providing developers with reliable access to historical community data and ongoing support for existing implementations.

**Areas:** Developer Relations · Community Intelligence · DevRel · Community Management · Member Tracking · Community Analytics · Open Source · Developer Engagement · Defunct
